# v0.1.2

- Removes the legacy v0.0.2 Token-to-key migration channel: `migrate-token-to-key.sh`, bootstrap `--mode migrate-token-to-key`, the agent's `-prepare-token-migration` / `-enroll-token-migration` entry points and the workflow migration asset. Release assets are now three scripts (bootstrap/install/upgrade), three binaries and checksums.txt.
- Hosts still running released v0.0.2 Token installations are no longer served by a panel command. Migrate them manually via the v0.1.1 transition tag (`git clone`, then `git checkout v0.1.1`) following that version's documentation, then upgrade through the regular channel. Already public-key hosts are unaffected; do not rerun migration after a regular upgrade.
- `install.sh --upgrade` now points to the regular upgrade entry instead of the removed migration script.

Deploy companion Monitor commit c2dbc01 (or later) for the matching removal of the panel migration command and the documented git-based Monitor upgrade method. Monitor is not deployed automatically.

Validation: both repositories' Go tests/vet; bootstrap mock tests and 18 deterministic signal-window cases including the arm64 install path; Monitor frontend 129 tests/build. No production deployment performed. An active service is not proof of authentication or report delivery: verify the reported version and fresh samples in Monitor after upgrading, and back up configuration and private key first.
